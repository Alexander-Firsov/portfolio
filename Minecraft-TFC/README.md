# Развертывание Stateful-приложения с высокой нагрузкой (Minecraft TFC)

Проект представляет собой реализацию концепции Infrastructure-as-Code (IaC) для развертывания капризного к ресурсам Stateful-приложения (серверная и клиентская части модификации TerraFirmaCraft) с продвинутой автоматизацией.

## 🚀 Запуск и оркестрация
Вместо прямого вызова `docker compose up` используется интеллектуальный скрипт автоматизации управления:
```bash
chmod +x start.sh # запускается единоразово после копирования файла в систему
sudo true # активация кеша sudo, он же родительский контроль
./start.sh [Имя_Игрока] [Время_Работы_В_Минутах]
```

## 🛠️ Эксплуатационные характеристики и автоматизация:
* **Интеллектуальный Healthcheck (Парсинг логов):** Скрипт `start.sh` реализует событийную модель запуска зависимостей. Вместо слепого ожидания (`sleep`), цикл `while` в реальном времени читает логи сервера, очищает их от ANSI-последовательностей (цветов терминала) с помощью регулярных выражений `sed` и запускает игровой клиент только после полной инициализации серверного ядра.
* **Мягкое завершение процессов (Data Integrity):** Для предотвращения повреждения базы данных мира (чанков) реализован Graceful Shutdown. Скрипт посылает корректный Unix-сигнал `pkill -15` (SIGTERM) для Java-клиента и осуществляет программную инжекцию команды `stop` напрямую в дескриптор ввода процесса сервера (`/proc/1/fd/0`). Это гарантирует полный сброс кэша приложения на диск перед остановкой.
* **Защита дисковой подсистемы (Ротация логов):** Игровые серверы генерируют огромные массивы логов. Настроена агрессивная политика ротации `json-file` (максимум 5 файлов по 10 МБ), что исключает риск переполнения диска (Disk Full) на хосте.
* **Проброс аппаратных ресурсов:** Реализовано низкоуровневое сопряжение контейнера с хостом — проброс прямой отрисовки видеокарты (`/dev/dri`), сокетов дисплейного сервера X11 и аудио-сервера `PulseAudio` для обеспечения аппаратного ускорения внутри изолированного окружения.
