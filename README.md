2. **Закрытые соревнования на Kaggle От Самокат (январь 2024)** - Задача по матчингу товаров. На публичной части данных было занято 21 место из 47, значение метрики f1 0.90567. *(Согласно правилам соревнования, исходный код и датасет являются приватными и не подлежат публикации)*
3. **[Автоматизация Stateful-приложения (Minecraft TFC)](./Minecraft-TFC-Infrastructure/)** — сложная docker-compose архитектура с продвинутым оркестровочным Bash-скриптом. **Проект разработан для автоматического ограничения времени игры детей за компьютером и реализации родительского контроля запуска.** Реализован событийный healthcheck по логам, жесткий таймер сессии и мягкое завершение процессов (SIGTERM) для защиты данных от повреждения при принудительном выключении.
4. **[Инфраструктура компиляции Python и OpenSSL в докер-контейнере](./Synology-Static-Compilation/)** — проект по сборке современного софта из исходников для устаревших проприетарных ядер (Synology NAS). Автоматизировал многопоточную сборку кастомных RPM-пакетов на Bash. **Собранные пакеты Python, OpenSSL и зависимости X11 (нужны для транзитного проброса X11) успешно развернуты, протестированы и стабильно работают на целевом NAS-устройстве.** Проект занял 3 недели интенсивной автономной работы и является наиболее технически сложным кейсом по низкоуровневой линковке и разрешению конфликтов зависимостей в моем портфолио.
5. **[Инфраструктура для локального ИИ (Ollama)](./Ollama/)** — развертывание LLM-моделей в контейнерах. Настроена жесткая изоляция ресурсов для предотвращения падения ОС по нехватке памяти (OOM).
