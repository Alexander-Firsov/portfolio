# Автоматизация сборки Python и OpenSSL под проприетарные ОС

Проект решает задачу обновления системных зависимостей на Synology NAS DSM в условиях отсутствия стандартных пакетных менеджеров.

## 🛠️ Особенности реализации и поддержка:
* **Контроль совместимости:** В `Dockerfile.builder` встроена автоматическая проверка версии системной библиотеки `glibc`, что предотвращает сборку несовместимых с целевым хостом бинарников.
* **Многопоточная сборка:** Скрипт `opt/host/make.sh` реализует асинхронный запуск процессов компиляции (`rpmbuild &`) с последующим контролем выполнения через `wait` и PID-массивы.
* **Патчинг на лету:** Скрипт автоматически модифицирует `.spec` файлы сборки через `sed`, принудительно включая флаги статической линковки (`--enable-static`) и кастомизируя секции упаковки файлов.
* **Безопасность снабжения:** Процесс сборки включает автоматическую верификацию GPG-ключей OpenSSL и проверку подписей исходного кода Python с помощью утилиты `cosign`.
