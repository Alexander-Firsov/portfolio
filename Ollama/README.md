# Инфраструктура для локального развертывания LLM (Ollama)

Данный подпроект содержит изолированное окружение для запуска локальных больших языковых моделей (например, DeepSeek Coder 6.7B) внутри контейнеров Docker. Архитектура спроектирована с упором на стабильность хост-системы и удобство администрирования.

## 🚀 Быстрый старт
Для сборки специализированного диагностического образа и запуска сервиса выполните:
```bash
docker compose up -d --build
```

## 🛠️ Инженерные особенности и механизмы поддержки:
* **Защита от OOM (Out of Memory):** Выставлены жесткие лимиты по оперативной памяти (capping на уровне 24GB) через `deploy.resources.limits`. Параметры `OLLAMA_NUM_PARALLEL=1` и `OLLAMA_MAX_LOADED_MODELS=1` гарантируют детерминированное потребление ресурсов и защищают ядро хост-машины от падения по нехватке памяти при обработке тяжелых контекстов.
* **Диагностический слой L2/L3:** Кастомный `Dockerfile` собирает образ на базе Ubuntu, куда принудительно предустанавливаются утилиты сетевой и системной отладки (`curl`, `jq`, `iputils-ping`, `mc`, `tree`). Это позволяет оперативно проводить траблшутинг REST API нейросети прямо изнутри контейнера.
* **Сохранение логов отладки:** История команд терминала внутри контейнера мапится на хост-машину (`./mnt/host/.bash_history`). Это позволяет сохранять аудит-лог действий инженера даже после полного пересоздания или падения контейнера.
* **Автоматический мониторинг (Healthcheck):** Состояние сервиса опрашивается каждые 30 секунд нативными средствами API (`ollama list || exit 1`), что позволяет оркестратору вовремя реагировать на зависание моделей.
